# 导出问题日志

1. 安装 0.1.1 (9) 或更新版本。
2. 打开「设置 → 问题诊断」，开启「记录诊断日志」。
3. 重现登录、分享解析或下载问题。
4. 返回设置，点击「导出诊断日志」，在 iOS 分享菜单中存储到文件。
5. 将 ZIP 发回来，同时说明平台、操作步骤、出错时间、界面提示、Wi-Fi/蜂窝网络和代理使用情况。

导出文件也会保存在「文件 → 我的 iPhone → YunX → Downloads」。
关闭记录后不会产生新的诊断事件，已有记录仍能导出。

日志包含版本、构建号、iOS 版本、导出时间、记录开关、日志丢弃计数，以及请求状态、耗时、
夸克业务状态、关键凭证是否齐全、网页登录错误、保存账号和网盘加载过程、下载任务阶段及异常类型/位置。
不会记录 Cookie、Token、密码、验证码、完整分享/下载 URL、请求响应正文或网盘文件列表。
历史记录上限为 10 MiB，导出时再次脱敏。仅诊断 ZIP 用于排查；账号认证备份是另一项功能。

空日志包通常表示未开启记录，或开启后尚未操作。先开启、重现一次，再导出即可。
